# Contribute

Use an issue to report an ambiguous term, source error, broken link or missing
example. Use a PR for a proposed change. People and tools follow the same process.

For a working definition, give its context, English and Portuguese wording,
references, an example, and a counterexample where confusion changes behavior.
Mark quotations and original editorial definitions separately. Do not label an
original paraphrase as an official translation or standard definition.

For a source change, identify the exact URL, edition/commit, permission and file
set. Update the fixed allowlist through review; do not edit snapshot files by hand.
Keep source notices and provenance. Do not submit private data or credentials.

Run the offline verifier and tests shown in README. Live refresh uses public
sources and explicit timeouts. A source failure must be visible, not converted
to a successful empty update. Maintainers review changes; no automatic merge.
